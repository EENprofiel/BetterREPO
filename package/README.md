# BetterREPO

A curated multiplayer modpack that improves R.E.P.O. without turning it into a completely different game.

BetterREPO focuses on removing common annoyances, making co-op progression smoother, improving the shop and inventory experience, supporting late joining, and adding more level variety with a handful of fun additions.

## What this pack focuses on

- Quality-of-life fixes for common gameplay annoyances.
- Smoother multiplayer and shared progression.
- Late joining with additional compatibility fixes.
- A more flexible shop and inventory progression.
- Persistent valuables left in the truck between levels.
- Extra handcrafted and themed levels for more run variety.
- Small fun additions without excessive gameplay bloat.

## Curated configuration

BetterREPO includes the tested configuration from the profile so players get the intended setup automatically.

Notable choices include:

- **AdvanceMyShop:** discounts enabled while normal overpricing is disabled.
- **LevelScaling:** persistent HUD display is disabled so scaling information stays out of the way during normal gameplay.
- **No Save Delete:** game-driven save deletion is blocked, manual deletion remains available, and multiplayer wipes do not automatically reload the previous save.
- **SharedUpgradesPlus:** upgrades are shared with the crew, late-join syncing is enabled, and modded upgrades are supported.

## Installation

1. Install **BetterREPO** through Thunderstore Mod Manager or r2modman.
2. Let the manager install all required dependencies.
3. Launch R.E.P.O. using **Start Modded**.
4. For the most consistent multiplayer experience, everyone should use the same BetterREPO version.

## Updating

Updates to the curated mod list or configuration are published as new BetterREPO versions. Install the update when it appears in your mod manager.
